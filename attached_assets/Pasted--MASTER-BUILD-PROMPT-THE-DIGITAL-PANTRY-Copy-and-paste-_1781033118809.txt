# CUT-OUT LETTER SYSTEM

This is a defining visual feature.

Create a reusable React component:

```tsx
<CutoutWord word="PINK" />
```

Each letter must:

* Have a different font
* Slightly different size
* Slight rotation
* Alternate colors

Colors rotate between:

* Hot pink
* Gold
* White
* Soft pink

Fonts rotate between:

* Bebas Neue
* Permanent Marker
* Playfair Display

The effect should resemble magazine cut-out letters.

Use this component for:

* PINK
* SCRATCH
* WORK
* PRICING
* Engineering Diva
